# Sprint Contract — F016: `.preview.yaml` app contract with components

Feature: F016 — per-repo app contract; chart renders N components; path routing on one host
Phase: 05 — Multi-repo, reusable platform
Date: 2026-09-30

## 1. Scope & Acceptance Criteria
- [ ] `.preview.yaml` at the app branch root: `components[]` (name, context, dockerfile, port, probePath, route, resources), `addons[]`
- [ ] Parsed with `yq` (preinstalled on ubuntu runners) → JSON → validated + normalized by pure jq `preview_config` (lib)
- [ ] No file → default `{components:[{name: web, context: .}]}`; this repo ships `.preview.yaml` (web=`todo` `/`, api=`examples/echo-api` `/api`)
- [ ] Workflow: plan job → build job (matrix per component, `docker/build-push-action`) → deploy job; build checks out the exact planned sha
- [ ] Images `<ACR>/<APP_IMAGE_NAME>/<component>:<sha>`; purge iterates `APP_IMAGE_NAME` + `APP_IMAGE_NAME/*` repos
- [ ] Chart: `components` value → Deployment/Service/HTTPScaledObject per component (`<release>-<component>`), HSO `pathPrefixes: [route]`;
      one Ingress `/` → interceptor (it routes host+path). Empty `components` → legacy single render, byte-identical to pre-F016 (golden file)
- [ ] verify: every component route returns 200
- [ ] Full verify green; e2e: this repo deployed with 2 components — `/` todo 200, `/api/health` JSON from api, both scale 0→1 on request

## 2. Edge cases & failure paths
- Config: not a mapping / empty file; unknown top-level or component keys (typos); 0 or >4 components; duplicate names/routes;
  bad name (upper, leading digit, >15, trailing -); port non-int / out of range; context/dockerfile absolute or with `..`;
  route/probePath not starting with `/` or unsafe chars; trailing `/` on route normalized; resources bad quantity / unknown keys;
  any addon → "unsupported" (none yet)
- yq missing → exit 2; unreadable/invalid YAML → exit 1 with message; nothing written to GITHUB_OUTPUT on failure
- Partial resources merge with chart defaults
- Purge: repo list unreadable → delete nothing; legacy `todo` repo still purged
- N/A: UI.

## 3. E2E scenario(s)
Dispatch Deploy for `feat/F016` → 2 matrix builds green → `https://feat-f016.preview.nimat.dev/` 200 (todo), `/api/health` 200 JSON;
wait idle → both deployments 0; request `/api/health` → api 0→1; Destroy → 404. Purge dry-run lists `todo` + `todo/*`.
