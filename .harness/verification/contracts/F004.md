Phase: 01 — Foundation
Date: 2026-09-28

## 1. Scope & Acceptance Criteria
Stage 1 (no DNS needed):
- [ ] Pinned versions in `bootstrap/versions.env` (traefik, keda, keda-add-ons-http, cert-manager) — BLK-004
- [ ] Every script: dry-run default, `--apply`, refuses unless kube current-context == `$AKS_NAME`
- [ ] A1 `a1-ingress.sh`: Traefik via Helm (`bootstrap/values/traefik.yaml`: ExternalName services
      allowed, HTTP→HTTPS redirect, IngressClass `traefik`); prints LB IP — bats + real apply
- [ ] A4 `a4-keda.sh`: KEDA core + HTTP add-on via Helm; verifies interceptor svc
      `keda-add-ons-http-interceptor-proxy:8080` exists — bats + real apply
- [ ] Spec chart validated server-side against the installed HTTPScaledObject CRD
      (`helm template … | kubectl apply --dry-run=server`) — closes the spec's version-drift risk
Stage 2 (identity; separate human OK — grants CI write access):
- [ ] A5 `a5-github-oidc.sh`: Entra app + SP + federated credential
      `repo:<GH_REPO>:environment:preview`; AcrPush on ACR; AKS Cluster User + RBAC Writer;
      enables AKS Entra integration + Azure RBAC if off (required for the RBAC roles/kubelogin)
- [ ] A6 `a6-github-env.sh`: `preview` environment + repo variables via `gh` (BLK-006 blocks apply)
Stage 3 (after Namecheap NS delegation, BLK-005):
- [ ] A2 wildcard A `*` in `preview.nimat.dev` → Traefik LB IP
- [ ] A3 cert-manager + DNS-01 (workload identity) + ClusterIssuer + wildcard Certificate Ready;
      Traefik default TLSStore uses it
Common:
- [ ] Idempotent re-runs; shellcheck; check-architecture; `./scripts/init.sh` GREEN
- [ ] E2E: `curl -k https://<anything>.preview.nimat.dev` served by Traefik with the wildcard cert (stage 3)

## 2. Edge cases & failure paths
- Wrong kube context → exit 1, no helm call — bats
- Missing env/versions → exit 2 — bats
- helm failure mid-way → non-zero, re-run converges (helm upgrade --install) — bats
- LB IP not assigned within timeout → exit 1 with message — bats
- Interceptor service missing/different port after A4 → exit 1 — bats
- A5 re-run: existing app/SP/federated credential/role assignments reused, not duplicated — bats
- N/A: UI, tenancy (single cluster/operator).

## 3. E2E scenario(s)
Stage 1: Traefik LB IP answers HTTP (redirect to HTTPS, 404 default); interceptor pods Ready;
server-side dry-run of the spec chart passes. Stage 3: wildcard TLS.

## 4. Plan
versions.env + traefik values → a1, a4 → fakes (helm, kubectl) + bats → real dry-run → apply
(stage 1) → server-side chart validation → a5/a6 (dry-run, human OK) → a2/a3 after NS.

## 5. Out of scope (parked)
- Scoped ClusterRole instead of RBAC Writer (F009). ACR retention (F011).

## 6. New dependencies
Traefik chart (replaces ingress-nginx, DEC-021).

## 7. Risks
- Traefik semantics vs nginx annotations: nginx annotations are ignored; Host is forwarded by default
  (interceptor routing depends on it) — verified in stage 1 via curl with Host header.
- Enabling AKS Azure RBAC changes how the operator authenticates (kubelogin) — stage 2 human OK.
