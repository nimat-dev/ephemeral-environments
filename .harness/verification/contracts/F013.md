# Sprint Contract — F013: Provision Azure prerequisites

Feature: F013 — AKS + ACR + DNS zone (spec Prerequisites)
Phase: 01 — Foundation
Date: 2026-09-28

## 1. Scope & Acceptance Criteria
- [ ] `bootstrap/provision.sh`: dry-run by default (prints mutating `az` commands, runs only
      read-only ones); `--apply` executes — bats: fake `az` log has no mutating verbs in dry-run
- [ ] Preflight (read-only): subscription reachable, resource group exists, providers registered
      (unregistered → `az provider register` planned), vCPU quota ≥ vcpus × (nodes + 1 surge)
      for the VM family and regional total — bats: quota too low → exit 1
- [ ] Idempotent: ACR / AKS / DNS zone each `show`-checked; existing → skipped — bats
- [ ] Existing AKS without OIDC/workload identity → `az aks update` planned — bats
- [ ] Creates Basic ACR, AKS (`--tier free`, N × size, OIDC + workload identity, managed identity,
      ACR attached), DNS zone; prints zone NS servers for Namecheap — bats (command shape)
- [ ] `bootstrap/teardown.sh`: prints only unless `--yes`; deletes AKS, ACR, zone; never the RG — bats
- [ ] Config from `bootstrap/.env` (gitignored) validated: required vars, ACR name `[a-z0-9]{5,50}`,
      node count ≥ 1, zone looks like a domain — bats: each invalid → exit 2
- [ ] shellcheck clean; check-architecture clean; `./scripts/init.sh` GREEN
- [ ] E2E (online, after human OK): `--apply`; `az aks show` provisioningState Succeeded;
      `kubectl get nodes` Ready; second `--apply` = all skipped

## 2. Edge cases & failure paths
- Missing env file / missing var / invalid ACR name / node count 0 / bad zone → exit 2
- Subscription not accessible → exit 1 before any mutation
- Resource group missing → exit 1 (we never create/delete the RG)
- Provider NotRegistered → register planned (dry-run) / executed (apply)
- Quota insufficient → exit 1 with numbers
- Partial failure: ACR created, AKS create fails → re-run skips ACR, retries AKS (idempotency) — bats
- Teardown on nothing-existing → all skipped, exit 0
- Unknown arg → exit 2
- N/A: concurrency (single operator), UI.

## 3. E2E scenario(s)
Real `--apply` against subscription1 after the human approves the dry-run (cost, DEC-019).
