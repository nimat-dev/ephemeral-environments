# Sprint Contract — F021: Kit extraction + releases

Feature: F021 — reusable preview kit (composite action + `workflow_call` workflows + chart), semver releases, dogfooded
Phase: 05 — Multi-repo, reusable platform
Date: 2026-09-30

## 1. Scope & Acceptance Criteria
- [ ] `kit/action.yml` composite action: runs `scripts/preview-ci.sh <command>` from the kit root (`github.action_path/..`),
      command via env (no `${{ }}` in `run:`), exposes the plan outputs
- [ ] Reusable workflows `kit-deploy|destroy|reap|purge.yml` (`workflow_call`): check the kit out at `kit_ref` (default = the
      release tag) into `.kit`, steps `uses: ./.kit/kit`; `vars.*` + `environment: preview` resolve in the caller repo;
      concurrency lives in the kit workflows (callers must not repeat the group)
- [ ] `.preview.yaml` `defaults` (lifetime, idle, maxReplicas): empty workflow inputs fall back to them, then 48h/30m/3
- [ ] This repo's four workflows are thin callers of the local kit at `github.sha` (dogfood)
- [ ] `scripts/kit-release.sh prepare|verify|publish-chart|github-release` + `kit-release.yml` (tag `vX.Y.Z` → verify all pins,
      chart to `oci://<ACR>/helm`, GitHub release); rule 7 exception for its `contents: write` (documented + tested)
- [ ] Consumer example `examples/consumer/` ≤ 25-line deploy/destroy caller + cleanup caller + `.preview.yaml`, full-tag pins
- [ ] Full verify green; e2e: dogfood Deploy/Destroy/Reap/Purge green; release v1.0.0 published (chart in ACR, GitHub release)

## 2. Edge cases & failure paths
- Defaults: invalid lifetime/idle/maxReplicas/unknown key/non-mapping → config error; explicit inputs win over defaults
- Release: non-semver prepare → exit 2; tag ≠ VERSION or any stale pin (one kit workflow, chart, example) → exit 1 before publishing
- Pins: local `./` refs allowed; comments mentioning `uses:` not treated as refs
- Composite outputs: GITHUB_OUTPUT inside a composite only surfaces via declared outputs (all plan keys declared)
- N/A: UI.

## 3. E2E scenario(s)
Dispatch Deploy (dogfood → kit-deploy → ./.kit/kit) for `feat/F021` → green, 2 routes verified; Destroy; Reap; Purge dry-run.
After merge: tag v1.0.0 → Kit - Release green → `helm show chart oci://nimatpreviewacr.azurecr.io/helm/preview --version 1.0.0`,
`gh release view v1.0.0`.

## 4. Plan
defaults (tests first) → composite → kit workflows → callers → release script/workflow → example → tests → init → e2e → PR → tag.

## 5. Out of scope (parked)
Splitting the kit into its own repo (DEC-037); a Marketplace listing.

## 6. New dependencies
None (helm OCI via `az acr login --expose-token`).

## 7. Risks
A kit workflow change needs `prepare` + release before consumers see it (dogfood runs the current commit, consumers the tag).
