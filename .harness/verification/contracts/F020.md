# Sprint Contract — F020: Repo onboarding module

Feature: F020 — OpenTofu `repo-onboarding`: per-repo identity, roles, GitHub env/vars, k8s guard
Phase: 05 — Multi-repo, reusable platform
Date: 2026-09-30

## 1. Scope & Acceptance Criteria
- [ ] Module (azuread 3.10, github 6.13, azurerm 5.7): Entra app + SP + federated creds (legacy + immutable subject), AcrPush +
      AcrDelete on ACR, AKS Cluster User on the cluster, GitHub env `preview` + 13 variables (incl. PREVIEW_APP/PREVIEW_DOMAIN)
- [ ] Generated k8s guard per repo: ClusterRoleBinding `preview-deployer-<app>` + VAP/VAPB `preview-deployer-guard-<app>`
      confining the SP to `preview-<app>-*`; written to `clusters/nimat/config/repos/` for Flux; old global guard removed
- [ ] `envs/nimat/repos.tf` onboards this repo by importing a5/a6's objects (21 imports, no recreate); re-plan No changes
- [ ] Live probes as the SP: own prefix allowed; other app prefix / bare preview- / kube-system / default denied
- [ ] BLK-008 resolved (identity + UAMI owned by OpenTofu → `tofu destroy`)
- [ ] a5/a6 marked superseded; full verify green; e2e Deploy + Destroy with the imported identity

## 2. Edge cases & failure paths
- Input validation: repository not owner/name, app not a ≤20 DNS label, subject not environment-scoped → plan fails
- Scope casing (`resourcegroups`) on the AKS role → no replacement
- Import ID formats (federated credential `{appObjectId}/federatedIdentityCredential/{id}`)
- Legacy pre-F015 `preview-<id>` namespaces are no longer writable by the SP (none exist; documented)
- N/A: UI.

## 3. E2E scenario(s)
Dispatch Deploy + Destroy for `feat/F020` (identity unchanged); after merge Flux prunes the old guard and applies the per-repo one.

## 4. Plan
module → env wiring + imports → plan to imports-only → apply → guard file → probes → tests → init → e2e → PR → verify Flux post-merge.

## 5. Out of scope (parked)
Onboarding the second repo (F023). Automatic lookup of the immutable OIDC subject (explicit input for now).

## 6. New dependencies
Providers azuread 3.10.0, integrations/github 6.13.0, hashicorp/local 2.9.1. GITHUB_TOKEN with repo admin for plans.

## 7. Risks
