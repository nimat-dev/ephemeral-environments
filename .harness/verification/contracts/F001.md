## 1. Scope & Acceptance Criteria
- [ ] `scripts/check-architecture.sh` enforces rules 1–9 of `rules/layer-boundaries.md`; output
      `file:line -> <match> -> rule N`, or `clean` — check: `bats tests/check-architecture.bats`
- [ ] Each rule skips cleanly when its target path is absent — check: bats "empty tree is clean"
- [ ] A violation of each rule exits non-zero naming the rule — check: 9 bats violation cases
- [ ] A spec-conformant tree (workflows sourcing lib, chart per spec) passes — check: bats "compliant tree"
- [ ] `--root DIR` lets it run against any tree (fixtures) — check: bats uses temp roots
- [ ] `scripts/init.sh`: warns on dirty tree; fails unless ROADMAP has exactly one `IN PROGRESS`;
      runs yamllint → shellcheck → actionlint → helm lint/template+kubeconform → bats →
      check-architecture; target absent → skip, tool missing but target present → fail;
      prints active feature + next step; exit non-zero lists failed steps — check: run it
- [ ] `.yamllint` excludes Helm templates, `node_modules`, lockfiles — check: `yamllint .` clean
- [ ] Logs `[level] <component>: msg` at start/end/failure — check: script output
- [ ] Boundary invariants: check-architecture passes on the repo itself.
- [ ] Edge/error cases from §2 covered by tests.
- [ ] E2E: N/A — not user-facing (dev tooling); `init.sh` run is the integration check.
- [ ] No regressions: `./scripts/init.sh` exits 0.

## 2. Edge cases & failure paths
- Empty → empty tree (no scripts/lib, no workflows, no chart) = clean, exit 0 (bats)
- Comments → forbidden words inside `#` comments are ignored (rules 1, 9) (bats)
- Near-miss names → `kubectl-like` identifiers / `helmfile` substrings don't trip rule 1 (bats)
- Allowed exception → `secrets.GITHUB_TOKEN` passes rule 3; `client-secret` / other `secrets.*` fail (bats)
- Missing block → workflow with no top-level `permissions:` fails rule 7 (bats)
- Extra permission → `packages: write` added fails rule 7 (bats)
- Multiple violations → all reported, not just the first (bats)
- Bad arg → `--root` missing dir exits 2 with message (bats)
- ROADMAP with 0 or 2 `IN PROGRESS` → init fails (bats, via `--roadmap-only`)
- N/A: concurrency, auth/tenancy, UI, data model — no runtime state or users.

## 3. E2E scenario(s)
N/A — not user-facing. `./scripts/init.sh` on the real repo is the end-to-end run.
