# Sprint Contract — F011: Env gate + ACR retention

Feature: F011 — `preview` env reviewers (optional) + ACR retention for preview SHA tags
Phase: 03 — Hardening
Date: 2026-09-29

## 1. Scope & Acceptance Criteria
- [ ] Env reviewers: SKIPPED by user decision 2026-09-29 (DEC-033) — deploy/destroy/reap all use env `preview`; a gate would stall the */30 reap
- [ ] ACR retention: `preview-acr-purge.yml` daily 03:17 UTC (+ dispatch: dry_run, max_age, keep) → `preview-ci.sh purge`;
      Basic SKU has no retention policy and ACR Tasks are blocked (DEC-025), so purge runs in Actions (DEC-034)
- [ ] SP gets `AcrDelete` (a5) — live
- [ ] Edge/error cases covered by bats (pure `purge_tags`/`preview_commits` + subcommand + workflow)
- [ ] check-architecture clean; actionlint/shellcheck/yamllint clean; FULL verify GREEN
- [ ] E2E: post-merge dispatch dry-run, then real purge (max_age 1h, keep 3) via the SP → tags gone, newest 3 kept

## 2. Edge cases & failure paths
- Never delete: tag of a live preview (`preview.commit` label), newest KEEP, delete-locked tag, non-sha tag (`latest`)
- Namespace list unreadable/malformed or tag list unreadable → exit 1, delete nothing (never purge blind)
- Nothing stale → exit 0 "nothing to purge"; one delete fails → others continue, run fails
- Config: missing ACR_NAME, bad age/keep/dry-run → exit 2 before any call
- Timestamps with fractional seconds parsed; empty tag list; malformed JSON → non-zero
- N/A: concurrency (own group, daily), UI.

## 3. E2E scenario(s)
Local operator dry-run on real ACR (pre-merge). Post-merge: dispatch dry_run=true, then dry_run=false max_age=1h keep=3.

## 4. Plan
pure lib → subcommand → workflow → a5 AcrDelete → bats → init → local dry-run → PR → merge → dispatch e2e.

## 5. Out of scope (parked)
Untagged manifests (buildx platform/attestation children of tagged indexes): deleting an untagged manifest can
break a live multi-manifest image; needs reference tracing. Basic's 10 GiB included storage makes it low-risk.

## 6. New dependencies
None.

## 7. Risks
`az acr repository delete --image` removes the manifest and every tag pointing at it — two SHA tags on one
digest would both go (only when both are stale and neither is in use by a live preview).
