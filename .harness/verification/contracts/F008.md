## 1. Scope & Acceptance Criteria
- [ ] Cron `*/30 * * * *` + manual dispatch — bats `reap workflow:`
- [ ] Deletes only `managed-by=preview-bot` ns with `expires-at < now`; otherwise "nothing to reap", exit 0 — bats `reap: deletes only expired`, `reap: nothing expired`
- [ ] Never touches non-preview namespaces: lists by label, and lib now also requires a `preview-` name — lib `expired_namespaces` (`default` with the label ignored)
- [ ] check-architecture / actionlint / shellcheck / yamllint clean; `./scripts/init.sh` GREEN
- [ ] E2E: preview with 1m lifetime reaped on the next run; live preview untouched

## 2. Edge cases & failure paths
- Empty list / nothing expired → exit 0, no delete — bats
- Boundary: `expires-at == now` not expired (lib test); missing / non-numeric label → expired (spec, DEC-017)
- Malformed list JSON / `kubectl get` failure → non-zero, no delete — bats
- Partial failure: one delete fails → the rest still deleted, run fails at the end — bats
- Foreign namespaces: label on `default` → ignored — lib test
- Concurrency: overlapping scheduled + manual runs → `concurrency: preview-reap`; delete is `--ignore-not-found` (idempotent)
- N/A: UI, auth variants (same OIDC path as deploy/destroy).

reap before expiry → nothing; after → only reap-short deleted, URL 404; reap again → nothing. Post-merge: scheduled run on main.
