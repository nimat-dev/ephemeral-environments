## 1. Scope & Acceptance Criteria
- [ ] `preview_id BRANCH` = spec sanitizer (lowercase, `[^a-z0-9]+`→`-`, trim `-`, cut 40, trim
      trailing `-`); empty result → return 1 — check: bats compares against the spec's inline
      pipeline over a corpus of branch names
- [ ] `preview_namespace ID` → `preview-ID`; `preview_host ID DOMAIN` → `ID.DOMAIN` — bats
- [ ] `to_seconds Nm|Nh|Nd` → seconds; anything else → return 1 — bats
- [ ] `idle_seconds` accepts `never` → 31536000, else `to_seconds` — bats
- [ ] `resolve_lifetime LIFETIME CUSTOM`: `custom` + empty CUSTOM → return 1 — bats
- [ ] `expires_at LIFETIME_VALUE [NOW]` = NOW + seconds; lifetime must be > 0 — bats
- [ ] `expired_namespaces NOW` (namespace-list JSON on stdin): names with
      `managed-by=preview-bot` AND `preview.expires-at < NOW`; missing label → expired — bats
- [ ] Pure: no adapter calls (check-architecture rule 1). Sourcing does not change caller shell
      options ("strict mode" = safe under a caller's `set -euo pipefail`; tests run that way).
- [ ] Boundary invariants: check-architecture clean.
- [ ] No regressions: `./scripts/init.sh` BASELINE GREEN.
- [ ] E2E: N/A — library (consumed by F006–F008).

## 2. Edge cases & failure paths
- Input/empty: empty branch, whitespace-only, all-symbol (`///`) → return 1
- Input/boundary: exactly 40 chars; 41+ chars where char 40 is `-` → trailing `-` trimmed
- Input/malformed: `-n` / `-e` branch names (echo pitfalls) → sanitized, not swallowed
- Input/unicode: accented + CJK + emoji → collapsed to `-` deterministically (`LC_ALL=C`)
- Input/duplicates: `a--b`, `a__b`, `a/-/b` → single `-`
- Durations/malformed: `12`, `h`, `1w`, `1.5h`, `-1h`, `` → return 1
- Durations/boundary: `0h` lifetime → return 1 (would expire immediately); `08h` (leading zero
  must not be read as octal) → 28800
- Expiry/boundary: `expires-at == now` → NOT expired (strict `<`)
- Expiry/missing: no `preview.expires-at` label → expired; non-numeric label → expired
- Expiry/tenancy: namespace without `managed-by=preview-bot` → never returned even if expired
- Expiry/empty: `{"items":[]}` → no output, return 0
- Expiry/malformed JSON → return non-zero
- N/A: concurrency, auth, UI — pure functions, no state.
