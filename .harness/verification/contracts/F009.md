# Sprint Contract — F009: Scoped k8s ClusterRole (preview-* guard)

Feature: F009 — restrict the CI SP's cluster writes to `preview-*` namespaces
Phase: 03 — Hardening
Date: 2026-09-29

## Baseline (live, 2026-09-29, `kubectl auth can-i --as=<sp>`)
ClusterRole `preview-deployer` (DEC-024/026) is cluster-wide: SP can create configmaps in
`kube-system`, delete ns `kube-public`, create deployments in `default`, create ns `foo`.
Secrets: already no. Azure roles: AcrPush + AKS Cluster User Role only (no RBAC Writer).

## 1. Scope & Acceptance Criteria
- [ ] SP bound to ClusterRole limited to preview resources — already true (DEC-024/026); bats `A5: spec's RBAC Writer…`
- [ ] Azure `RBAC Writer` not assigned; F006–F008 still pass — live `az role assignment list` + Deploy/Destroy dispatch under the policy
- [ ] ValidatingAdmissionPolicy `preview-deployer-guard` (+ binding, `Deny`), matched only for username == SP object id:
      namespaces: name must start `preview-`; every other write: request namespace must start `preview-`
      (cluster-scoped non-namespace writes denied) — bats renders it with the SP id
- [ ] Negative tests: SP cannot write secrets/configmaps in `kube-system`, create ns `foo`, delete a
      non-preview ns — a5 `--apply` self-check with `--dry-run=server --as=<sp>` (exits 1 if the guard
      isn't effective) + bats with fake kubectl
- [ ] Boundary invariants: check-architecture clean; shellcheck/yamllint clean
- [ ] FULL verify `./scripts/init.sh` GREEN

## 2. Edge cases & failure paths
- Boundary names: `preview` (no dash), `xpreview-a`, `previewfoo` → denied; `preview-a` → allowed (CEL `startsWith('preview-')`)
- Bulk: `deletecollection` (empty name) → denied
- Other identities (operator, system, KEDA) → unaffected (matchCondition on SP username) — live dry-run as operator
- SelfSubjectAccessReview / TokenReview (auth API) → excluded so `can-i` still works for the SP
- Policy not yet effective after apply (propagation) → probes retried; still permissive → exit 1
- Dry-run a5 → prints manifest, mutates nothing, no probes
- N/A: input encoding, concurrency (admission is per-request).

## 3. E2E scenario(s)
Live a5 `--apply` → probes pass. Dispatch `Deploy Preview` + `Destroy Preview` on a test branch under the
policy → green, URL 200 then 404. Evidence `.harness/evidence/F009/`.

## 4. Plan
VAP in a5 `rbac_manifest` → probe function → fake kubectl `--dry-run=server` → bats → init → live apply → dispatch e2e → PR.

## 5. Out of scope (parked)
Per-namespace RoleBindings (would need a controller to bind on create); OPA/Gatekeeper.

## 6. New dependencies
None (VAP is GA in k8s 1.30; cluster is 1.35).

## 7. Risks
Real SP username must equal its object id (true for the existing ClusterRoleBinding, DEC-024) — the dispatch run proves it.
