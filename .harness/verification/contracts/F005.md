# Sprint Contract — F005: Smoke test (spec Part C)

Feature: F005 — `scripts/smoke.sh`, the Phase 01 e2e
Phase: 01 — Foundation
Date: 2026-09-28

## 1. Scope & Acceptance Criteria
- [ ] `scripts/smoke.sh --image REPO --tag TAG [--domain D] [--idle S] [--keep]`: namespace
      `preview-smoke`, release `smoke`, chart with `idleTimeoutSeconds=S` (default 120) and
      `ingressClassName=traefik`; trap deletes the namespace on exit unless `--keep`
- [ ] CP1 valid HTTPS: strict curl (system CA) to `https://smoke.<domain>/` → ssl_verify_result 0
- [ ] CP2 cold start: wait until Deployment has 0 replicas (proves scale-to-zero), then one request
      → HTTP 200 and replicas ≥ 1 (proves wake-on-request); record cold-start latency
- [ ] CP3 back to zero: replicas return to 0 within idle + 180 s
- [ ] Deterministic: every wait polls real state with a deadline; no blind sleeps as assertions
- [ ] Output: one line per checkpoint `CPn PASS|FAIL <detail>`; exit 0 only if all pass
- [ ] bats with fakes: arg validation, cleanup trap, CP failure paths (never reaches 0, non-200)
- [ ] Real run against aks-preview: 3/3 PASS; log in `.harness/evidence/F005/`
- [ ] init GREEN; check-architecture clean

## 2. Edge cases & failure paths
- Missing --image/--tag → exit 2; unknown arg → exit 2
- Replicas never reach 0 before deadline → CP2 FAIL, exit 1, namespace cleaned
- Wake request non-200 / timeout → CP2 FAIL
- TLS invalid → CP1 FAIL
- Interrupted run → trap still deletes namespace
- N/A: auth (no app auth), concurrency (single smoke release)

## 3. E2E scenario(s)
This is the e2e: real image from ACR → chart → Traefik → interceptor → pod, sleep → wake → sleep.
