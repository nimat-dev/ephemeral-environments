## 2. Edge cases & failure paths
- Empty / all-symbol branch → plan exit 1, no outputs — bats `plan: invalid input`
- `custom` lifetime empty / bad unit / zero → exit 1 — lib `preview_plan: every invalid input`
- max_replicas 0, > quota pods (6), non-numeric, huge → exit 1 — lib `max_replicas`
- Malformed / injection: branch with quotes, `$()`, backticks → only in jq-escaped annotation; no `${{ }}` in `run:` — bats `namespace_manifest`, `workflow: no expression interpolation`
- Type coercion: branch `null`/`true` or sha `1234e56` via `--set` breaks the chart → `--set-string` — bats `deploy passes strings via --set-string`
- Missing repo variable → exit 2 naming it — bats `plan/deploy: missing env`
- Downstream failure: helm fails → step fails — bats; URL never 200 → exit 1 after N attempts — bats
- Idempotency: redeploy same branch → `kubectl apply` + `helm upgrade` same release (lifetime re-armed) — e2e
- Concurrency: two dispatches same branch → serialized by `concurrency` group — bats (shape)
- Auth: SP has no secrets access → configmap driver forced in script, not only env — bats `HELM_DRIVER=configmap`
- N/A: UI (Actions UI is GitHub's), cross-tenant (single cluster, namespace per preview).
