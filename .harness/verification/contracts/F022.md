# Sprint Contract — F022: Agent-agnostic harness

Feature: F022 — the harness works the same for GitHub Copilot, Claude Code and any other agent (and humans)
Phase: 05 — Multi-repo, reusable platform
Date: 2026-09-30

## 1. Scope & Acceptance Criteria
- [x] Root `AGENTS.md` canonical; `CLAUDE.md` = `@AGENTS.md` (+ Claude imports); `.github/copilot-instructions.md` pointer
- [x] `.harness/commands/*.md` (start-session, start-feature, finish-session) single source → `scripts/sync-agent-commands.sh`
      renders `.claude/commands/harness-*.md` and `.github/prompts/harness-*.prompt.md` (quoted YAML front matter)
- [x] `scripts/harness-check.sh`: roadmap gate, state rule (`--staged` / `--range`), mirrors in sync
- [x] Enforcement in git + CI: `.githooks/pre-commit`; `harness-check.yml` on PRs + main (read-only token, rule 7
      extended); required status check on `main`
- [x] Copier template `templates/harness` (generic files copied by `scripts/build-harness-template.sh`, drift-tested;
      project files as Jinja; Claude hooks optional); a rendered repo passes its own gate
- [x] check-architecture rule 6 pattern from `.harness/rules/architecture.conf`
- [x] Full verify green

## 2. Edge cases & failure paths
- Gate: status = last backtick span; 0 / 2 IN PROGRESS fail; all COMPLETE/DEPRECATED pass
- State rule: harness-only change passes; code change without PROJECT_STATE fails (staged and range); bad range → exit 2
- Mirrors: stale after editing the source → fail; foreign prompt files untouched by sync
- Template: stale generic copy → fail; render with and without Claude hooks
- N/A: UI.

## 3. E2E scenario(s)
The F022 PR itself runs the `harness-check` workflow (required); a commit without PROJECT_STATE is rejected by the hook.

## 4. Plan
commands + sync → harness-check → hook + CI + rule 7 → entry files → rule 6 config → template + build script → tests →
init → PR (CI check green) → branch protection.

## 5. Out of scope (parked)
Publishing the template as its own repo (DEC-037); Copilot coding-agent hooks.

## 6. New dependencies
Copier (latest, pipx) — only for rendering/updating the template (test skips if absent).

## 7. Risks
Required check on `main` blocks merges when the check fails — intended; admins are not enforced (break-glass).
