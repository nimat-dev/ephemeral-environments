# Sprint Contract — F018: OpenTofu infra stack

Feature: F018 — `platform/` OpenTofu: `team-cluster` module + `envs/nimat` instance adopting the live resources
Phase: 05 — Multi-repo, reusable platform
Date: 2026-09-30

## 1. Scope & Acceptance Criteria
- [ ] OpenTofu v1.12.6 (latest), azurerm ~> 5.7 (latest v5.7.0); lock file committed
- [ ] `bootstrap/a0-tofu-state.sh`: state storage (Entra-only, versioning, TLS1.2, no public blobs) + container + Key Vault
      (RBAC, purge protection) + RSA key (encrypt/decrypt) + operator roles; dry-run default, idempotent
- [ ] Backend `azurerm` (use_azuread_auth, blob lease lock); `encryption` with `azure_vault` key provider, `enforced` for state + plan
- [ ] Module `team-cluster` (RG data-only): AKS (1 node, Free, OIDC + WI, Entra + Azure RBAC, overlay), ACR Basic + kubelet AcrPull,
      base DNS zone, cert-manager UAMI + federated credential + DNS Zone Contributor
- [ ] `envs/nimat` imports the 7 live resources: plan = 7 import, 0 add/change/destroy; after apply `tofu plan` = No changes
- [ ] Remote state blob is ciphertext (no plaintext resources / kube_config)
- [ ] `init.sh`: tofu fmt -check, offline validate per stack, `tofu test` (mock provider), tflint (azurerm ruleset), checkov (justified skips)
- [ ] Bash `provision.sh` kept (DEC-042)

## 2. Edge cases & failure paths
- a0: invalid names → exit 2; unregistered KeyVault provider → registered; existing key with wrong ops → set-attributes;
  RBAC not yet effective → bounded retries then exit 1; everything present → no mutation
- Module inputs: bad ACR name / node_count 0 → validation errors (tofu test expect_failures)
- Import drift traps found and fixed: linux_profile ssh key (would replace AKS), role scope `dnszones` casing (would replace
  role), `default_node_pools` provider default (ignore_changes)
- N/A: UI, e2e user flow (no behavior change; proof = no-change plan + preview workflows still green).

## 3. E2E scenario(s)
Live: a0 --apply (idempotent rerun), `tofu plan` (7 imports only) → `tofu apply` → `tofu plan` No changes; state blob encrypted.
Regression: dispatch Deploy + Destroy on `feat/F018` → green (cluster untouched by adoption).

## 4. Plan
tools → a0 → module → env + imports → iterate plan to zero diff → apply imports → tests/lint → init → e2e regression → PR.

## 5. Out of scope (parked)
In-cluster add-ons (F019 Flux); per-repo identity + GitHub vars + project domains (F020); CI running tofu plan on PRs.

## 6. New dependencies
OpenTofu 1.12.6, tflint 0.64.0 + azurerm ruleset 0.32.0, checkov 3.3.20 (all local/init.sh; checksums verified on install).

## 7. Risks
Purge-protected Key Vault: the state key cannot be purged for 7 days after delete (intended — losing it loses state).
Lost Key Vault access = unreadable state → a0 grants the operator Crypto Officer; blob versioning keeps old ciphertexts.
